Proposed State Schema Definition

class ValidatorState(TypedDict):
    ticker: str
    holdings: List[str]          # Populated by Fetch Holdings
    research_data: dict[str, str] # Populated by Research (Company -> News)
    evaluations: dict[str, dict]  # Populated by Analyze (Company -> Score/Summary)
    final_report: str            # Populated by Generate Report
